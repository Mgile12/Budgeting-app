# Reference

Visual references for function and style. Drop images here as they're collected — screenshots, mockups, app inspiration, color palettes, animation refs, whatever sharpens the build.

Suggested layout if it gets crowded:

- `function/` — screenshots of flows you want to copy or avoid (payday allocators, tap-log UIs, envelope grids, error states)
- `style/` — palette, typography, animation references, mood boards

PNG / JPG / WebP all fine. Vector (SVG) preferred for icons.
